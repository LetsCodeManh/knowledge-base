# Knowledge base

What I learned about AI and the tools around it, written so anyone can use it, technical or not.
Every claim links to its source, at the minute or the heading it comes from.

## Read it

- New here? Start with a path in [paths.md](paths.md).
- Everything, by topic: [topics.md](topics.md).
- Each note is one file in [notes/](notes/).

## Use it with an agent

Point Claude Code, Codex or any coding agent at this folder. [AGENTS.md](AGENTS.md) tells it how to find a note,
cite it and add one. It comes with a research skill, in `.claude/skills/`.

## Contribute

A fix or a new note is welcome as a pull request. How a note is written: [writing.md](writing.md).
Public sources only, and every claim cited.
