# Claude Code

_Claude working on your computer: you say what you want in plain words, it reads files, runs commands and makes the changes._

Claude Code is Claude working on your computer. It is an [agent](ai-agent.md): older coding assistants added a line or
two at a time, and Claude Code builds whole features, writes whole files and fixes bugs across them
([Anthropic, 1:08](https://www.youtube.com/watch?v=6eBSHbLKuN0&t=68s)). You say what you want, and it works out how to do it ([Anthropic, 7:52](https://www.youtube.com/watch?v=6eBSHbLKuN0&t=472s)).

## What it is

- **A few simple tools.** It can edit files, run commands and search files, and it combines them on its own
  ([Anthropic, 7:52](https://www.youtube.com/watch?v=6eBSHbLKuN0&t=472s)).
- **Where it runs.** In the terminal (the text window where you type commands), next to any editor ([Anthropic, 1:08](https://www.youtube.com/watch?v=6eBSHbLKuN0&t=68s)), because people at Anthropic use
  many different editors ([Anthropic, 25:54](https://www.youtube.com/watch?v=6eBSHbLKuN0&t=1554s)). Or inside VS Code, a code editor, through an add-on, for anyone who would
  rather not use the terminal ([Nate Herk | AI Automation, 1:11](https://www.youtube.com/watch?v=B6k_vAjndMo&t=71s)).
- **Nothing to prepare.** It builds no index of your code, so it starts at once ([Anthropic, 5:04](https://www.youtube.com/watch?v=6eBSHbLKuN0&t=304s)).

## How you talk to it

Like you would to a colleague: describe the goal, answer its questions, say when something is wrong. You do not need
to read code; what matters is saying clearly what you want ([Nate Herk | AI Automation, 5:59](https://www.youtube.com/watch?v=B6k_vAjndMo&t=359s)).

It can ask before each edit, edit on its own, or only plan ([Nate Herk | AI Automation, 25:18](https://www.youtube.com/watch?v=B6k_vAjndMo&t=1518s)): see Plan mode and
Sandbox and permissions. Press Esc at any time to stop it. The session is not harmed, and you can tell it what to
do instead ([Anthropic, 19:41](https://www.youtube.com/watch?v=6eBSHbLKuN0&t=1181s)).

## What it is not

- **Not only for code.** It has built n8n workflows ([Nate Herk | AI Automation, 0:00](https://www.youtube.com/watch?v=B6k_vAjndMo&t=0s)). A speaker from Anthropic has it
  read the project history each Monday and report what they shipped ([Anthropic, 6:30](https://www.youtube.com/watch?v=6eBSHbLKuN0&t=390s)).
- **Not always right.** It does not always follow its instructions ([Claude, 0:02](https://www.youtube.com/watch?v=IkaPHiMDazM&t=2s)).
  Check what it made: Let Claude Code build n8n workflows.

## Where to start

Ask about a project before you ask for changes. Anthropic teaches its new engineers this way,
and says their onboarding went from two or three weeks to two or three days ([Anthropic, 4:13](https://www.youtube.com/watch?v=6eBSHbLKuN0&t=253s)). The questions
show what it does alone and where it needs your help ([Anthropic, 7:20](https://www.youtube.com/watch?v=6eBSHbLKuN0&t=440s)).
